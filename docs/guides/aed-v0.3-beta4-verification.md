# AED Translator V0.3.0-beta.4 Windows 试用记录

## 两种模式共用翻译服务和麦克风

在「设置 → 语言与会话组成」选择实时翻译服务，在「设置 → 音频 → 麦克风」选择本机输入设备。「在线会议」和「面对面」读取同一组选择。面对面页面只需选择两种字幕语言，需要时再打开第三种。

升级后，面对面旧版本单独保存的服务不会覆盖会议设置。面对面保留原先选好的字幕语言。目前支持 Qwen LiveTranslate 和 OpenAI Realtime Translate。若共享设置选了其他服务，面对面会提示支持范围，并提供前往翻译设置的按钮。

从面对面点击「开始收音」会打开设置中选定的麦克风。麦克风设为「关闭」或没有可用输入时，页面提供前往麦克风设置的按钮。在线会议的对方音源和译音输出仍按各自用途工作。

## Windows 打包版验证

- 用独立配置从首次设置进入面对面，实际窗口只显示第一、第二和可选的第三字幕语言。将第三语设为英语后，重启仍为英语。
- 在设置中从 Qwen 改为 OpenAI Realtime Translate，重启后通过应用控制接口读到在线共享配置和面对面有效服务均为 `openai_translate`。改选通用 OpenAI Realtime 时，面对面禁用收音并提供设置入口。改回 Qwen 后再次核对，两处都显示 `qwen_livetranslate`。
- 共享麦克风设为「关闭」后重启，「开始收音」禁用。通过控制接口尝试开始也被拦住，未创建采集会话。在设置选回本机 Realtek 麦克风后，按钮随即恢复，之前的关闭提示消失。
- 本机有一支可选的实体麦克风。双设备切换、设备失效及虚拟线缆的选择规则通过模拟设备回归验证。本轮聚焦设置共享，全程未调用翻译 API。
- 44 个相关测试文件中的 699 项用例通过。全仓 TypeScript 检查返回 93 条已有诊断，与 beta.3 基线对照没有新增诊断。

## 包内文件

解压后打开 `AED Translator.exe`。同目录的 `AED-Audio-Report.cmd` 用于 Windows 音频诊断，会短暂播放测试音，在桌面生成带时间戳的 TXT 报告。交付前已校验其内嵌 PowerShell 的语法及 WAV 测试音。本包中的《完整验证记录》同时收录 beta.3 的个人 API、三语字幕、音色及回声测试。
