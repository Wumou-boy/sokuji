# AED Translator V0.3.6 · Windows x64

## 使用

解压后运行 AED Translator.exe。应用沿用当前 Windows 用户原有的配置和会议历史。在线会议的对方音源默认使用系统声音，之前保存的「自动」也会迁移到系统声音。如果已手动选过应用或设备，仍沿用该选择。系统采集会收到同时播放的其他应用声音。

麦克风沿用 Sokuji 0.51.2 的浏览器采集约束和回声消除选项。AED 移除了后来添加的 AEC3、根据对方参考音轨削弱声音、延迟缓存和自动选源轮询。会话中的基线回声监测仍可给出提示。

打开在线会议页时，AED 会根据当前系统播放设备显示可关闭的提醒。系统使用扬声器时建议戴耳机；切到耳机后提醒消失。设备类型未知时不推断佩戴情况。这里检测的是系统播放路由，Teams 单独指定输出时，应以 Teams 所选设备为准。

面对面收音时，成功保存不会反复弹出提示。录音或字幕保存失败时仍会提示。在「历史」打开某场会话即可播放原声，点一句字幕旁的 ▶ 会从对应位置开始回听。

## 验证 · 2026-11-29

| 检查 | 结果 |
| --- | --- |
| Windows 启动与迁移 | 在独立配置中模拟旧 Auto 设置，启动成品后读取到 System，旧设置键已清空。使用日常配置打开成品，版本为 0.3.6、设备已就绪、对方音源为 System。 |

| 麦克风传给识别端的样本 | 双向会议收音回归覆盖近端轻声、麦克风与对端完全相同、双方同时说话。检查每个样本与输入相等，而且麦克风一帧到达就同步交给订阅者。 |
| 面对面保存和回听 | 通过成品界面输入两段日语合成语音，用本地模拟识别服务返回字幕。正常停止后未显示保存成功提示。重启后读回整段 9.82 秒原声；点第二句，播放器在 5.546 秒开始播放并高亮该句。 |
| 回归与打包 | 159 个相关测试文件、2,307 项通过，仓库默认跳过一组回声检测参数扫描。两个 Windows 诊断脚本集成用例通过。生产构建通过，115 个前端 JavaScript 文件与成品逐字节一致。成品未包含 AED AEC3 的 WASM 模块。 |

仓库全量类型检查还有 90 条既有诊断，上一版为 93 条。多语言一致性检查仍有既有缺项和占位符差异；逐一比对上一版实际分发的 29 个非英语语言包，未发现本版新增差异。此次验证覆盖软件采集和回放路径，未用公司 Teams 真人会议测量云端识别率。

压缩包还附有 AED-Audio-Report.cmd 和 AED-Teams-Live.cmd，供需要时采集诊断。日常开会无需运行脚本。
