# AED Translator V0.3.0-beta.6 面对面麦克风电平

在「面对面」点击「开始收音」。按钮旁的「麦克风」条和 dBFS 数值显示当前输入音量。数值越接近 0 dBFS，输入越响。静音显示为空条和 −∞ dBFS。停止收音会立即清零，音频中断超过 300 毫秒也会清零。

电平取自本场送给翻译服务的同一份音频，每 100 毫秒更新显示。它使用「设置 → 音频」已经选好的麦克风。打开页面时不会为了显示电平单独启动麦克风。

## Windows 打包版验证

2026 年 11 月 28 日，用现有个人百炼配置在 beta.6 的面对面会话回放 10.352 秒合成音频，夹具含两段发言和结尾 3 秒静音。24 kHz 单声道输入共 248,448 个样本。通过应用控制接口读取实时峰值，并通过 Playwright 读取桌面窗口的电平条和 dBFS 读数。

- 回放期间捕获 35 个运行时峰值和界面读数同时为正的采样点。静音尾段显示空条和 −∞ dBFS，停止会话后仍为零。
- 在 420、600、960 像素宽的窗口中，电平条、收音按钮和 Token 读数互不重叠，工具栏无横向溢出。
- 软件回归覆盖麦克风输入、静音音频帧、音频断流、停止时的清零以及延迟回调。14 个相关测试文件、135 项测试通过。全仓 TypeScript 检查的 93 条既有诊断与 beta.5 基线相同。

这轮桌面测试使用合成回放，未录制现场人声。安装包沿用现有配置，附带 r2 版 Windows 音频诊断 CMD。上游基线仍为 Sokuji 0.51.2。
